# 🎬 Gold Reels: סטודיו רילס בעברית בתוך Claude

**אתם יושבים על מכרה זהב.** ההרצאות, הלייבים, הוובינרים והפודקאסטים שכבר הקלטתם יכולים להפוך לעשרות רילס.
הסקיל הזה הופך את Claude לעורך וידאו אישי:
- מתמלל עברית
- קורא את כל התמלול
- מוצא את הרגעים החזקים ביותר
- חותך אותם לרילס אנכיים עם כתוביות בעברית, כותרת פתיחה וכרטיס סיום

בלי לדעת לערוך, ובלי לדעת לתכנת.

> נבנה על ידי [יואב יושע](https://www.instagram.com/yoav_yosha/) · קוד פתוח (MIT) · חינם

## מה צריך
- אפליקציית **Claude** לדסקטופ, עם מנוי בתשלום (Pro ומעלה). עובדים בלשונית **Code**. להורדה: [claude.ai/download](https://claude.ai/download)
- **Mac** (macOS 12 ומעלה) או **Windows** 10/11
- כ-**6GB** פנויים וחיבור לאינטרנט. ההתקנה מורידה כ-2.5GB, פעם אחת.

## התקנה (פעם אחת, 10-20 דקות, רובן הורדות)

**1. מתקינים את הסקיל.** פותחים את Claude ← לשונית Code ← סשן חדש, ומדביקים:

```
תתקין לי את הסקיל gold-reels מהקישור הזה:
https://github.com/YOYOAQUA/gold-reels
תוריד את הקבצים, תשים אותם בתיקיית הסקילים של Claude, ותבדוק שיש בתיקייה קובץ SKILL.md.
בסוף תגיד לי לפתוח סשן חדש.
```

**2. מתקינים את הסטודיו.** פותחים **סשן חדש** וכותבים:

```
תתקין לי סטודיו רילס
```

Claude יתקין הכל בתוך תיקייה אחת (`GoldReels`) ויראה לכם סרטון בדיקה קצר.
רוצים להסיר? מוחקים את התיקייה.

## איך עובדים
1. פותחים סשן חדש **בתיקייה GoldReels**.
2. שמים סרטון בתיקייה `input`.
3. כותבים: *"שמתי בתיקיית input הרצאה שלי. תמצא לי את הרגעים הכי חזקים לרילס"*.
4. Claude מתמלל, מציע רגעים עם ציטוטים וזמנים, ו**עוצר לאישור שלכם** לפני החיתוך ולפני הרינדור.
5. הרילס המוכנים מחכים בתיקייה `output`.

**כל הפרומפטים המלאים, עם כפתור העתקה, והדרכת וידאו מלאה:** [yoavyosha.ravpage.co.il/zahav](https://yoavyosha.ravpage.co.il/zahav)

## שאלות נפוצות
- **כמה זה עולה?** הסקיל חינמי. צריך מנוי Claude בתשלום.
- **כמה זמן לוקח תמלול?** במחשב ממוצע, בערך כמו אורך הסרטון. אפשר להשאיר ללילה.
- **Claude מבקש אישור על כל פעולה?** זה תקין. קוראים מה הוא רוצה לעשות ומאשרים.
- **משהו לא עובד?** כתבו ל-Claude: *"הסטודיו לא עובד, תריץ בדיקה ותתקן"*.
